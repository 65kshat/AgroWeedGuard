# 🌱 AgroWeedGuard

### AI-Powered Weed Detection and Classification System

AgroWeedGuard is an AI-based agricultural monitoring platform developed as an internship capstone project. It combines multiple computer vision models with an AI Assistant to detect, classify, compare, and interpret weed-related predictions from field images.

---

## 📌 Overview

AgroWeedGuard allows users to:

- Upload one or multiple agricultural field images.
- Detect weeds using YOLOv8 or Faster R-CNN.
- Classify weeds using CNN (ResNet18) or Vision Transformer (ViT).
- Compare model predictions, confidence scores, and inference times.
- Preserve model results during the current application session.
- Send accumulated model results to an AI Assistant for analysis.
- View model evaluation metrics and project information through the interface.

> **Note:** Model predictions are AI-generated results and are not guaranteed ground truth.

## 🤖 AI Assistant

AgroWeedGuard includes an AI Assistant that interprets the outputs generated by the computer vision models.

The assistant can:

- Identify detected or classified weeds.
- Compare model predictions when possible.
- Highlight agreements and disagreements.
- Identify unusually high or low confidence predictions.
- Point out uncertain results.
- Provide useful agricultural context.
- Avoid treating model predictions as guaranteed ground truth.

The AI Assistant uses an external LLM API to analyze the collected model results.

⚠️ Limitations
Model predictions depend on image quality and environmental conditions.
Confidence scores do not guarantee correctness.
Model performance depends on the quality and diversity of the training data.
The AI Assistant interprets model outputs and does not independently verify plant identity.
Agricultural decisions should not be based solely on automated predictions.
Real-world deployment would require additional validation across different fields, crops, lighting conditions, and geographical regions.
